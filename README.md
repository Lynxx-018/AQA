# Postman Echo API Tests

Автотесты для API **Postman Echo**.  
Проект содержит **два подхода** к тестированию одного и того же API.

---

## 📌 Вариант 1: Коллекция Postman

Импортируй файл `postman-collection/PostmanEchoCollection.json` в Postman.

**Запуск:**  
Открой коллекцию → **Run** → выбери папку **Request Methods** → запусти.

---

## 🛠️ Вариант 2: Java + RestAssured

Автотесты на Java с использованием RestAssured.

**Технологии:**
- Java 17
- RestAssured 
- TestNG 
- Maven
